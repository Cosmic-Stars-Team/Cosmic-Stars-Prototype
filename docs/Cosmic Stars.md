# Cosmic Stars — 项目文档

## 一、第一阶段目标

基于 REBOUND + REBOUNDX 实现完整 N 体模拟，涵盖：

- 潮汐锁定
- 引力弹弓
- 水星近日点进动（含 GR 修正开关对比，展示 43″/ 世纪的广义相对论效应）
- 太阳演化对轨道的影响（通过 MIST 网格插值太阳质量变化，驱动 REBOUNDX 的 `modify_mass`）

长期积分采用 **Mercurius** 积分器。

## 二、轨道要素基础

六大开普勒轨道根数决定星体运动，这是 Cosmic Stars 最初的物理基础：

| 参数 | 符号 | 物理意义 |
|------|------|----------|
| 轨道半长轴 | $a$ | 轨道大小 |
| 偏心率 | $e$ | 轨道形状 |
| 轨道倾角 | $i$ | 行星轨道面相对于黄道面的夹角 |
| 升交点黄经 | $\Omega$ | 轨道平面在三维空间的取向 |
| 近日点角距 | $\omega$ | 椭圆长轴在轨道面内的方向 |
| 过近日点时刻 | $\tau$ | 行星在轨道上的位置 |

**天球坐标约定**：x 轴指向春分点（♈︎ 点，γ 点）。

![常用的几种天球坐标系统](file:///D:/Development/Cosmic-Stars/docs/media/global/image1.jpeg)

在太阳系中，除水星外各大行星轨道偏心率均很小（近圆形），轨道倾角也很小（近共面），这与太阳系行星相似的演化路径有关。

这六个参数决定了星体的运动，是 Cosmic Stars 最初的物理基础。

## 三、积分器选型

本项目选用 **REBOUND** 及其扩展库 **REBOUNDX** 进行第一阶段的模拟。

传统数值方法（Runge-Kutta 及 RKF 自适应步长）在长期模拟中能量不守恒，系统能量会随时间发散。REBOUND 采用**辛积分器**，模拟保守哈密顿系统具有高效、稳定的特点。对于太阳系的行星动力学极其有效。

REBOUND 集成了多种积分器，这里主要介绍 WHFast、Mercurius、IAS15、EOS 四种，也是项目未来使用的核心积分器。

对此 Cosmic Stars 采用分工明确的策略：对于目前第一阶段的太阳系工作，采用 **Mercurius** 是工程上和科学性上的最优解。

### 3.1 WHFast

Wisdom-Holman Fast 积分器。适用于存在主导中心天体且开普勒轨道扰动较小的系统。支持一、二阶辛校正器以及 [Wisdom 等人 (1996)](https://ui.adsabs.harvard.edu/abs/1996FIC....10..217W/abstract) 提出的核方法，并支持多种不同的核函数。

**核心原理**：WHFast 摆脱了传统牛顿迭代法求解开普勒超越方程 $M = E - e\sin E$ 的系统性截断误差，使用哈密顿算子分裂将 N 体系统拆解为开普勒运动主导项和微扰项（如行星间的相互作用），采用跳蛙 (Leap-frog) 方式交替计算：

1. **Drift（漂移）**：让行星沿着完美的开普勒椭圆轨道飞半个时间步长
2. **Kick（踢）**：在当前位置，计算所有行星之间的相互作用力，瞬间改变它们的速度（动量）
3. **Drift（漂移）**：再次沿着新的开普勒轨道飞行半个步长

参考 [Rein & Tamayo (2015)](https://ui.adsabs.harvard.edu/abs/2015MNRAS.452..376R/abstract)

### 3.2 IAS15

高精度自适应步长积分器，非辛，15 阶精度。基于 Gauß-Radau 求积法（隐式预测-校正器）。

- 适合强动力学模拟（如引力弹弓）
- 是目前双精度浮点数 (FP64) 极限内最精准的积分算法
- 优势：可实现任意力

### 3.3 Mercurius

内部集成 WHFast 和 IAS15，在处理近距离交会时可平滑切换到 IAS15，远距离时保持 WHFast 的速度和辛优势。可通过修改希尔半径相关代码控制切换条件。

### 3.4 步长选择

参考 [Rein, Brown & Tamayo (2019)](https://academic.oup.com/mnras/article/490/4/5122/5601761)：

- 能量误差不适合作为太阳系模拟的唯一收敛性评价指标
- 有效步长范围约为 dt = 1–10 天。小于 1 天后精度受舍入误差主导不再提高
- 木星质量是水星的 5000 多倍，但水星公转周期比木星短 50 倍——轨道误差对总能量的贡献不成比例
- Cosmic Stars 将步长选在 1–10 天之间，具体取值需经 Python 后端数值验证

以 IAS15 结果为参考标准：

![收敛性对比](file:///D:/Development/Cosmic-Stars/docs/media/global/image2.png)

即使积分步长设为 10 天，WHFast 在长达 2000 年的模拟中仍可保持精度优势，可以尝试将 dt 设为 1、4、8 天来应对不同场景。但工程化和可视化的实现远比满足模拟精度要困难得多。

## 四、多速率积分与辛桥 (Symplectic Bridge)

### 4.1 问题背景

太阳系面临多时间尺度挑战：木卫一轨道周期约 1.2 天，木星公转周期约 10 年。若对全系统采用统一 dt，为分辨卫星运动所需的极小步长将导致计算成本急剧上升。

对于短周期卫星，如果仍然采用统一的时间步长 dt，问题会变得不可行。例如木卫一的轨道周期约为 1.2 天，而木星绕日公转周期约为 10 年。为了分辨卫星运动所需的极小 dt，整体计算成本会急剧上升，超出一般计算资源的承受范围。

### 4.2 早期错误尝试——时间插值法

最初做法：以地月系为例，开辟两个模拟——主系统模拟太阳和地月质心，子系统模拟地月系并引入太阳潮汐力。为了让子系统在小步长积分时知道太阳位置，需要对太阳轨迹进行时间插值，从而引入了对时间 t 的显式依赖。

```math
H = H(q,p,t)
```

**致命问题：**

- 插值导致哈密顿量显式含时，系统变为**非自治**的
- 相空间流形不再静态，辛算法赖以保持的"能量有界震荡"前提被破坏
- 随时间变化的外力像幽灵一样对系统做功
- 子系统受太阳引力，但地月对太阳的反作用未能同步到主系统，破坏动量守恒和平移对称性
- 时间可逆性被破坏，耦合系统无法保持影子哈密顿量，长期积分必然出现能量漂移

项目因此一度陷入停滞。

### 4.3 解决方案路线

此前犯过的错误：

1. 认为子系统在运行 $\delta t$ 时需要实时知道太阳位置 → 尝试对太阳坐标做时间插值 → 能量发散
2. 认为主系统可以不感知子系统 → 不满足牛顿第三定律 → 动量不守恒
3. 试图将 REBOUND 作为一个不可拆分的整体调用 → 无法在积分器底层步进中插入潮汐修正

在解决多速率积分架构时，项目参考了 **Embedded Operator Splitting (EOS)** 思路。在此过程中，**Prof. Hanno Rein** 提供了宝贵的指导，包括：

- 对多时间尺度耦合问题的分析
- 在子系统中处理外部潮汐力时避免显式时间依赖
- 对算子分裂（Kick-Drift-Kick / Symplectic Bridge）实现的建议

### 4.4 EOS：显式算子分裂

所有辛积分器都基于同一个数学前提：系统的总哈密顿量 $H$ 可以被拆分为两个或多个可精确求解的子部分。

$$H = H_A + H_B$$

如果我们定义算子 $\hat{H} = \{H, \cdot\}$（李导数），系统从 $t=0$ 到 $t=\Delta t$ 的状态演化可以写成：

$$z(\Delta t) = e^{\Delta t \hat{H}} z(0)$$

根据 **Lie-Trotter 乘积公式**：

$$e^{\Delta t (\hat{A} + \hat{B})} = \lim_{n \to \infty} (e^{\frac{\Delta t}{n} \hat{A}} e^{\frac{\Delta t}{n} \hat{B}})^n$$

当步长 $\Delta t$ 足够小时，可以通过轮流执行 $A$ 和 $B$ 的演化来逼近 $A+B$ 同时作用的效果。

在 REBOUND 架构中具象化为两个算子：

**Drift 算子 $\hat{D}$**：代表系统在没有任何外部扰动情况下的自然演化。在 WH 映射中，天体沿完美开普勒轨道运行。**位置变化，动量不变。**

**Kick 算子 $\hat{K}$**：代表系统受到的相互作用力。时间冻结，根据当前几何位置计算引力并直接修改天体动量。**位置不变，速度离散跳跃。**

### 4.5 辛桥 (Symplectic Bridge) 方案

三层哈密顿量分裂：

$$H = H_{\text{main}}(Q,P) + H_{\text{sub}}(q,p) + H_{\text{cross}}(q,Q)$$

其中各项物理含义：

| 项 | 物理内容 | 积分方式 |
|------|----------|----------|
| $H_{\text{main}}$ | 日-行星二体（如太阳+地月质心） | 大步长 $\Delta t$ WHFast |
| $H_{\text{sub}}$ | 行星-卫星多体 | 小步长 $\delta t = \Delta t / N$ WHFast |
| $H_{\text{cross}}$ | 太阳对卫星系的潮汐力 | 大步长 $\Delta t$ 离散 Kick |

**二阶 Strang 分裂**：

$$e^{\Delta t(\hat{H}_{\text{main}} + \hat{H}_{\text{sub}} + \hat{H}_{\text{cross}})} \approx e^{\frac{\Delta t}{2}\hat{H}_{\text{cross}}} \cdot e^{\Delta t(\hat{H}_{\text{main}} + \hat{H}_{\text{sub}})} \cdot e^{\frac{\Delta t}{2}\hat{H}_{\text{cross}}}$$

具体步进序列：

1. **半部 Kick** ($\Delta t/2$)：基于当前全相空间计算潮汐力梯度，修改子系统和主系统动量
2. **完整 Drift** ($\Delta t$)：两个 REBOUND 模拟独立推进到同一目标时间
3. **半部 Kick** ($\Delta t/2$)：在新位置重新计算潮汐力，再次修改动量

**BCH 公式误差分析**：

$$e^{\frac{\Delta t}{2}\hat{C}} e^{\Delta t(\hat{A}+\hat{B})} e^{\frac{\Delta t}{2}\hat{C}} = e^{\Delta t(\hat{A}+\hat{B}+\hat{C}) + O(\Delta t^3)}$$

Strang 分裂对称性使 $\Delta t$ 奇次项抵消，整体达到**二阶精度**。

**潮汐力公式**：

$$\mathbf{a}_{\text{tidal}}(\mathbf{r}_i) = \mathbf{a}_{\text{sun}}(\mathbf{r}_i) - \mathbf{a}_{\text{sun}}(\mathbf{r}_{\text{bary}})$$

$$\mathbf{a}_{\text{sun}}(\mathbf{r}) = -\frac{GM_{\text{sun}}}{|\mathbf{r}-\mathbf{r}_{\text{sun}}|^3}(\mathbf{r}-\mathbf{r}_{\text{sun}})$$

去掉质心受力是因为那部分已被 $H_{\text{main}}$ 中的日-行星二体吸收。

**关键性质**：

- **自治**：$H_{\text{cross}}$ 仅依赖当前全相空间 $(q,Q)$，不显式依赖时间 $t$
- **动量守恒**：主系统通过反作用力闭环接收子系统的反馈
- **时间可逆**：对称的 KDK 序列保证二阶精度

### 4.6 对齐采样陷阱

曾踩过的坑：收敛测试显示 ~1 阶而非预期 2 阶。

**原因**：不同 dt 的积分在不等价的时刻采样。若每固定步数记录一次，dt 不同则采样时间也不同，输出混入了 O(dt) 的采样误差。

**修复**：对齐到全局参考时间序列：

```python
# 错误做法：每 N 步记录（采样时间随 dt 漂移）
while t < t_end:
    step()
    if step_count % 10 == 0:
        record()

# 正确做法：对齐固定时间网格
sample_times = linspace(0, t_end, n_samples)[1:]
for target_t in sample_times:
    while t < target_t:
        step(min(dt, target_t - t))
    record()
```

### 4.7 三组验证测试

#### 测试 1：倒置日心坐标（"杀死引力"）

将主系统日心坐标中的太阳移到 $10^6$ AU 外，使潮汐力 ≈ 0。地月系退化为孤立二体，WHFast 保持轨道不变。

- 输入：潮汐力 ≈ $10^{-6}$ 量级
- 输出：地月距离恒定，能量守恒
- 结果：通过 ✓

#### 测试 2：收敛阶测试

在 365d–2920d 范围内扫描外步长，以最细步长为参考计算 RMS 误差：

| dt 对比 | RMS 误差比 | 收敛阶 |
|---------|-----------|--------|
| 365d → 730d | 4.3× | 2.1 |
| 730d → 1460d | 4.9× | 2.3 |
| 1460d → 2920d | 5.2× | 2.4 |

理论期望二阶（步长减半误差降 4×），实测 4.3–5.2×，确认二阶收敛。

- 结果：通过 ✓

#### 测试 3：能量诊断

1 年积分，地月系能量涨落 $\Delta E_{\text{rms}} \approx 10^{-8}$，长期无漂移。

- 结果：通过 ✓

### 4.8 与原始 KDK 对比

原始 KDK（单向 Kick，仅子系受力，无反馈）：

$$\text{Kick}_{\text{sub}} \to \text{Drift}_{\text{sub}} \to \text{Drift}_{\text{main}} \to \text{Kick}_{\text{sub}}$$

辛桥（双向 Kick，动量闭环）：

$$\text{Kick}_{\text{sub+main}} \to \text{Drift}_{\text{sub}} + \text{Drift}_{\text{main}} \to \text{Kick}_{\text{sub+main}}$$

二者在短期模拟中结果几乎相同（地月系 EMB 反作用极小），但辛桥保证了长期动量守恒和可扩展性。

### 4.9 架构同构性

辛桥架构对地月系和木卫系完全同构：

| 层次 | 地月系 | 木卫系 |
|------|--------|--------|
| H_main | 太阳 + 地月质心 (a=1 AU) | 太阳 + 木星系质心 (a=5.2 AU) |
| H_sub | 地球 + 月球 | 木星 + 伽利略卫星 |
| H_cross | 太阳潮汐力 | 太阳潮汐力 |

**易错点**：木卫质量通常以 $M_{\text{JUP}}$ 为单位，需换算为 $M_{\text{sun}}$。若直接使用原始数值，卫星质量偏大 1000×，WHFast 的"摄动 << 中心势"前提崩溃。

**木卫系验证**（50 年积分）：

| 卫星 | 周期 | 误差 |
|------|------|------|
| Io | 1.769 天 | < 0.1% |
| Europa | 3.552 天 | < 0.1% |
| Ganymede | 7.154 天 | < 0.1% |
| Callisto | 16.67 天 | < 0.1% |

谐振角 $\phi = \lambda_{\text{Io}} - 3\lambda_{\text{Europa}} + 2\lambda_{\text{Ganymede}}$ 锚定在 180°（理论拉普拉斯共振平衡点）附近做大幅天平动，dφ/dt 仅 0.05 rad/yr，与 µ 值完全自洽。

### 4.10 潮汐力量级分析

$$\frac{F_{\text{tidal}}}{F_{\text{bind}}} \approx 2 \cdot \frac{M_{\text{sun}}}{M_{\text{planet}}} \cdot \left(\frac{a_{\text{moon}}}{a_{\text{planet}}}\right)^3$$

| 系统 | 比值 | 实际意义 |
|------|------|----------|
| 地月系 | 1.8% | 不可忽略 |
| 火星-火卫 | ≈ 7×10⁻⁶ | 可省略潮汐耦合 |
| 木卫系 | ≈ 4×10⁻⁷ | 可省略潮汐耦合 |
| 土卫系 | ≈ 4×10⁻⁶ | 可省略潮汐耦合 |

对外行星，卫星系可独立积分而不加日心潮汐耦合。辛桥在外行星系的核心价值**不是潮汐耦合精度**，而是**多尺度步长分离**——避免让木星跟着内卫星运行小步长。

## 六、前端工程化

### 6.1 时间尺度同步

项目涉及三个时间概念：

| 时钟 | 来源 | 说明 |
|------|------|------|
| 现实时钟 (FPS) | 玩家 | Godot 以 60 fps 运行，每 1/60s 更新一次画面 |
| 游戏时钟 | 用户调节 | 如 15 年/现实秒 |
| 积分时钟 (dt) | REBOUND | 后端积分器步长 |

若用户调节 15 年/现实秒，每帧需推进 91.3 天，后端需计算 11.4 步。这对实时计算不现实。

**解决方案**：Godot 前端不直接渲染当前物理状态，而是从数据缓冲区中插值读取。

### 6.2 插值策略

当游戏时钟足够小时（如 1 秒/秒），积分器相邻两步之间天体位移可能很大。为保证画面连贯性，采用**三次埃尔米特插值法**：

- 保证流形上的 C¹ 平滑（位移 + 速度连续）
- 时间复杂度 O(1)，具有良好的局部性
- 相比自然三次样条（O(N)）更适合实时渲染

使用埃尔米特插值时，前端不仅要传入星体的笛卡尔坐标，也需要传入三个维度的速度。（没有写完）

自适应步长的 IAS15 同样可以使用埃尔米特插值法，需加入自适应步长修正（未完待续）。

## 七、第三阶段目标：相对论黑洞可视化

### 7.1 概览

黑洞作为广义相对论最极端的物理预言，其强引力场下的时空极度扭曲效应（光子球、引力透镜、相对论多普勒频移等）是现代天体物理学可视化的巅峰挑战。

**Cosmic Stars 拒绝任何形式的视觉欺骗与纯美术贴图近似**，选择在 Godot 4 中使用着色器 (Shader) 实现类"星际穿越"的黑洞可视化。

### 7.2 核心方法：从拉氏量到光线追踪

从广义相对论的作用量原理出发，利用史瓦西时空的球对称性（角动量守恒），推导光子在赤道面内的有效势能，得到在着色器中可高效计算的光子向心加速度公式：

$$\vec{a} = - \frac{1.5 R_s L^2}{r^5} \vec{x}$$

**推导流程**：

1. **拉格朗日量**：光子在弯曲时空中沿类光测地线传播，$ds^2 = 0$

$$\mathcal{L} = \frac{1}{2} g_{\mu\nu} \frac{dx^\mu}{d\lambda} \frac{dx^\nu}{d\lambda} = 0$$

代入史瓦西度规并将轨道限制在赤道面 $\theta = \pi/2$：

$$\mathcal{L} = \frac{1}{2} \left[ -\left(1 - \frac{R_s}{r}\right) c^2 \dot{t}^2 + \left(1 - \frac{R_s}{r}\right)^{-1} \dot{r}^2 + r^2 \dot{\phi}^2 \right] = 0$$

2. **诺特定理** → 守恒律：

- 时间平移对称 → 能量 $E = (1 - R_s/r) c^2 \dot{t}$
- 空间旋转对称 → 角动量 $L = r^2 \dot{\phi}$

（在代码中 `L2 = dot(L_vec, L_vec)` 就是角动量平方。）

3. **有效势能**：

$$\dot{r}^2 + V_{eff}(r) = \frac{E^2}{c^2}, \quad V_{eff}(r) = \frac{L^2}{r^2}\left(1 - \frac{R_s}{r}\right) = \frac{L^2}{r^2} - \frac{R_s L^2}{r^3}$$

4. **加速度**：$\vec{a} = -\nabla V_{eff}$

$$a_{rel} = -\frac{1}{2} \frac{d}{dr} \left(-\frac{R_s L^2}{r^3}\right) = \frac{3 R_s L^2}{2 r^4} = \frac{1.5 R_s L^2}{r^4}$$

矢量形式（方向指向黑洞中心 $-\vec{x}/r$）：

$$\vec{a} = - \frac{1.5 R_s L^2}{r^4} \frac{\vec{x}}{r} = - \frac{1.5 R_s L^2}{r^5} \vec{x}$$

结合 **RK4 积分器 + Raymarching** 即可实现高精度引力透镜效果。

### 7.3 渲染优化

#### 远近场分层

- **近场 (Volumetric RK4)**：在吸积盘包围球内步进累积光学厚度与相对论红移
- **远场 (Early Exit)**：光线逃逸后提取守恒量，查 Rust 后端离线计算的 **2D LUT 纹理**获取剩余偏折角。经罗德里格斯旋转公式将 O(N) 积分降为 O(1) 查表

#### 2D LUT 预处理

对背景 EXR 文件预处理成 2D LUT 纹理，节省远场计算。需验证衔接平滑性与实时交互可行性。

### 7.4 吸积盘渲染

不模拟真实 GRMHD（算力不允许），采用**体积着色盘 + 物理色温表**策略：

- 引入吸积率 $\dot{M}$ 作为唯一物理驱动，温度场 $T \propto (\dot{M}/r^3)^{1/4}$
- 计算多普勒因子 $\delta$ 与引力红移因子 $g_r$：$T_{obs} = T_{base} \cdot \delta \cdot g_r$
- Python 预烘焙 **4096×1 HDR 色温映射表 (Temperature 1D-LUT)**，GPU 端仅需 UV 纹理采样
- 通过红移补偿与防污染截断保证"左侧蓝移炽白、右侧红移暗淡"的物理准确性

### 7.5 资产与缓存优化

背景星空使用 16-bit 4K EXR 贴图配合 Mipmaps + 线性过滤。在光子环等画面极度拉伸区域，利用 GPU 底层低频滤波实现自然抗锯齿。
